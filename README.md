# SteelBall-Detection 钢球检测

基于 **CanMV K230** 与 **YOLO11** 的钢球实时检测与坐标偏差输出项目。摄像头实时采集画面，通过 YOLO11 模型检测画面中的钢球，计算钢球中心与屏幕中心的 X 轴偏差，并叠加抗闪烁与滤波算法保证输出稳定，最终通过 **UART2 串口** 将偏差数据发送给外部下位机（如舵机云台 / 弹射机构控制板），实现自动追踪钢球。

## 功能特性

- 🎯 **YOLO11 目标检测**：基于 `steelball2.kmodel`（320×320 输入），单框检测钢球位置
- 📡 **串口联动输出**：每帧通过 UART2（115200 baud）发送协议帧，协议简单易对接
- 🔒 **抗闪烁 / 抗丢帧**：最多缓冲 3 帧连续丢失，偶发漏检不掉线，避免输出抖动
- 📉 **位置平滑滤波**：X 轴偏差采用 70% 当前帧 + 30% 上一帧的加权滤波，抑制数值剧烈跳动
- 🖥️ **可视化 OSD**：屏幕上绘制检测框、中心十字线、中间 1/3 检测区域边界线及状态文字（绿色=检测到 / 红色=未检测）
- 🚀 **高帧率运行**：采用 PipeLine 流水线处理，逐帧推理并 `gc.collect()` 控制内存

## 系统架构

```
┌──────────────────┐   YOLO11 推理   ┌──────────────────┐
│  Sensor 摄像头    │ ───────────────▶ │  坐标偏差计算      │

                                     │  下位机 (MCU/舵机) │
                                     └──────────────────┘
```

## 硬件需求

| 部件 | 说明 |
|------|------|
| 主控板 | CanMV K230（支持 CanMV 固件） |
| 摄像头 | K230 配套 Sensor（ID=2，输出 1280×720） |
| 显示屏 | 3.5 寸 ST7701 LCD（800×480） |
| 模型文件 | `steelball2.kmodel`（放入板载 `/models/` 目录） |
| 串口 | UART2：GPIO11 → TX2，GPIO12 → RX2（TTL 电平，与下位机共地） |

## 使用方法

1. 将 `models/steelball2.kmodel` 上传到板卡 `/models/` 目录
2. 将 `main.py` 上传到板卡 `/` 根目录
3. 按上表接线（摄像头、LCD、UART2）
4. 运行 `main.py` 即可自动开始检测，串口实时输出协议帧

## 串口协议

波特率：**115200**，8 数据位 / 无校验 / 1 停止位，每帧以 `\r\n` 结尾：

| 场景 | 协议帧 | 说明 |
|------|--------|------|
| 检测到钢球（且在中间 1/3 区域内） | `X{偏差}Y0Z1E` | 偏差 = 球心 X − 屏幕中心 400，例如 `X+35Y0Z1E` |
| 未检测到（或超过 3 帧丢失） | `X0Y0Z0E` | 视为无效目标 |

> `Z` 位可理解为“目标存在标志”（1=存在，0=不存在），下位机可直接按帧解析驱动云台/机构动作。

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| `conf_thresh` | 0.65 | 置信度阈值（降低以提升边缘/动态捕捉能力） |
| `nms_thresh` | 0.45 | NMS 阈值 |
| `max_boxes_num` | 1 | 最多输出 1 个检测框 |
| `MAX_MISS_FRAMES` | 3 | 抗闪烁：允许连续丢失帧数 |
| 位置滤波 | 0.7 / 0.3 | 当前帧 / 上一帧加权 |
| ROI 区域 | 画面纵向 1/3 ~ 2/3 | 仅统计中间 1/3 区域内的钢球 |

如需调整，直接修改 `main.py` 顶部的常量即可。

## 注意事项

- 屏幕中心原点为 (400, 240)，偏差计算基于球心 X 坐标
- 检测区域限定为画面纵向中间 1/3（两条白色横线之间），区域外的检测结果不生效
- 程序退出（Ctrl+C 或异常）时会自动释放串口、模型与显示资源
- 若误检率高可上调 `conf_thresh`；若丢帧抖动明显可增大 `MAX_MISS_FRAMES`
